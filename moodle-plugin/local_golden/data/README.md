# GeoLite2 database location

Place the MaxMind **GeoLite2-City.mmdb** file in this directory.

Download (free, registration required): https://www.maxmind.com/en/geoip2-databases

Default expected path:
`<MOODLE_ROOT>/local/golden/data/GeoLite2-City.mmdb`

You can override this in **Site administration → Plugins → Local plugins → GOLDEN → GeoLite2 database path**.
